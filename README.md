# 改稿本 (Gaigao PWA)

专为网文作者打造的手机端极速改稿、划词批注、一键排版与 AI 两步式指令生成工具。

支持部署为 PWA（渐进式 Web 应用），在 iPhone Safari 中一键「添加到主屏幕」即可作为独立 App 离线使用。

---

## 核心特性

### 1. 📱 单界面边改边批（轻装上阵，零格式负担）
- **点哪改哪**：整页即文本编辑区，无富文本排版包袱，自动持久化保存到手机本地 IndexedDB。
- **划词批注**：长按或滑动选中句子，选区浮出「💬 批注」按钮，半屏抽屉式填入修改要求，不跳页、不打断思路。
- **高亮带标**：被批注原句呈现温和黄色高亮并标注 ①②③ 编号；点击高亮处可随时查看或修改意见。
- **智能锚定**：正文编辑或一键排版后，批注自动重锚定位置；若原句彻底删改，置灰提示「原句已删」，并在导出清单中保留原句引用。

### 2. 📊 精准字数统计（对标 VMark 与番茄平台规范）
- **核心字数**：精确计算字符数（不含空格，码点对齐，正确计算 Emoji），与番茄后台官方计字完全一致。
- **多维指标**：一键查看总字符数、中文汉字数（CJK）、自然段落数与平均段长。
- **节奏诊断**：自动评估段落长度，提供移动端网文 25~45 字黄金呼吸感与爽点节奏建议。

### 3. ✨ 一键规范排版（1:1 继承 VMark 网文特调算法）
- 自动清除每段段首全角空格（`\u3000`）与英文空格，依靠排版样式自然呈现段落感。
- 清除每段段尾冗余空白符。
- 智能压缩连续多余空行，统一规范为标准双换行（`\n\n`）。
- 保留 Markdown 结构（标题、代码块、表格等）。
- 排版时智能迁移批注位置，保证批注永不丢失。

### 4. 📋 两步式 AI 改稿指令（防偷改、防幻觉、先审后落盘）
点击「生成指令 📋」一键生成防乱改提示词，内置严格的两步式执行准则：
- **第一步：先出修改方案，不要动文件**
  - 要求 AI 逐条写出「原句 → 改后句」并说明改法；
  - 仅限修改带 ①② 批注范围，其余作者亲手改动的地方原样保持；
  - 遇到矛盾或需连带修改的内容单独汇报。
- **第二步：确认后再改文件**
  - 作者回复“通过”后，AI 落实修改并清扫 ①② 标记落盘。

### 5. 💾 数据安全与离线支持
- **离线工作**：完全运行在客户端本地，支持飞行模式或无网络环境下码字改稿。
- **备份与恢复**：支持一键导出包含全部章节与批注的完整 JSON 备份文件，随时跨设备导入恢复。

## iPhone Safari 安装指南

1. 在 iPhone Safari 浏览器中打开部署链接（如 GitHub Pages 地址）。
2. 点击 Safari 底部分享按钮（带向上箭头的方框）。
3. 向下滚动并选择 **「添加到主屏幕」**。
4. 点击右上角 **「添加」**，桌面即可生成「改稿本」App 图标，启动后全屏沉浸、无地址栏干扰。
